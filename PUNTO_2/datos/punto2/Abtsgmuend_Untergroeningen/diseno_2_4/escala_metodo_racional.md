# Escala y validez del método racional

El método racional se acepta aquí para la microcuenca de 0.123154 km². La tabla `escala_metodo_racional.csv` muestra una comparación numérica al aumentar el área, usando una longitud proxy proporcional a la raíz del área y FRA ilustrativos decrecientes.

Para 10 y 100 km² la hipótesis de lluvia uniforme y un único tiempo de concentración ya es débil. Para la cuenca del punto 1 (2363.302 km²) el método racional **no se usa como diseño**: un único pluviómetro no representa la variabilidad espacial, la duración crítica deja de ser local y el FRA domina el resultado. Los valores de esas filas son demostrativos, no recomendaciones hidráulicas.
