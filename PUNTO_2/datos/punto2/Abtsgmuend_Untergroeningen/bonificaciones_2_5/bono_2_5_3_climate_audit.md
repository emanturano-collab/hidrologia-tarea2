# Auditoría climática

El escalamiento 7 % por °C fue calculado como escenario de sensibilidad. La estación DWD usada para este punto no contiene temperatura observada; por tanto, no se afirma una tendencia térmica ni se otorga automáticamente el bono 2.5.3. Para cerrarlo se requiere una serie térmica coincidente o una fuente oficial independiente y una justificación del ΔT.
