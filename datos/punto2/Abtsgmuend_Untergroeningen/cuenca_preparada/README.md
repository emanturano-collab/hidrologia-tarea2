# Cuenca preparada

La delimitación reproducible se obtuvo con flujo D8 y priority-flood sobre el
MDE SRTM N48E009. El área es 0.123154 km² y el outlet sintético coincide con el
extremo aguas abajo del cauce derivado del DEM. La estación DWD 00020 está
fuera del polígono, por lo que se usa como referencia regional de lluvia.

Archivos principales: `cuenca_resumen.csv`, `microcuenca_mask.npy`,
`dem_ventana_m.npy`, `microcuenca_abtsgmuend.geojson`, `cauce_principal.geojson`
y `puntos_control.geojson`.
